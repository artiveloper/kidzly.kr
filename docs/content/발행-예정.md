# 발행 예정 — 후보 20편

> 작성일 2026-08-17 · 최종 갱신 2026-08-18 · 클러스터 3개 · 후보 제목 20개
> 발행이 끝나면 이 문서에서 해당 항목을 지우고 [발행-완료.md](./발행-완료.md)로 옮긴다.

**D1은 2026-08-17, D3은 2026-08-18 발행 완료했다.** 그 과정에서 확인된 원문 사실은 아래 "D1 리서치로 확정된 사실"과 "D3 리서치로 확정된 사실" 두 절에 정리해 두었다. 남은 D클러스터와 B클러스터 글은 다시 조사하지 않아도 된다.

## 왜 이 주제들인가

[발행-완료.md](./발행-완료.md)에서 확인했듯 기존 19편은 **지원금과 제도**에 쏠려 있다. 어린이집 실무 글 5편도 전부 입소 이전 단계이고, 입소 이후를 다룬 글은 `어린이집-하루일과-연령별` 하나뿐이다.

부모가 어린이집을 다니는 내내 검색하는 **생활 영역**(준비물, 낮잠, 결석 대처)이 통째로 비어 있다. 이 문서는 그 빈자리를 3개 클러스터로 나눈 것이다.

조사 방법은 구글·네이버 노출 정보성 페이지 취합이다. 네이버 블로그탭·지식iN 원문은 직접 수집되지 않아, 검색엔진에 실제 노출되는 공공 포털·개인 블로그·육아 미디어 기준으로 정리했다.

## D1 리서치로 확정된 사실 (2026-08-17)

D1을 쓰면서 **2026년도 보육사업안내**(교육부, 발간등록번호 11-1342000-100026-10) 원문 PDF를 직접 열람해 확인한 내용이다. 팩트체커가 PDF를 독립적으로 재추출해 교차 검증했다. **D2·D5는 이 표를 근거로 삼으면 되고 다시 조사할 필요가 없다.**

원문 PDF는 [여기](https://www.scscc.or.kr/child/file/2026_childcare_body.pdf)에서 받을 수 있다(성남시육아종합지원센터 배포본).

### 출석일수별 보육료 지원 비율

| 월 출석일수 | 지원 |
|------------|------|
| 11일 이상 | 부모보육료 단가 100% |
| 6~10일 | 50% |
| 1~5일 | 25% |
| 0일 | 미지원 |

**0·1세(0~23개월)는 출석일수와 무관하게 전액 지원**된다. 특례 확인도 불필요하다.

### 출석인정특례 사유별 상한

| 사유 | 상한 |
|------|------|
| 아동 질병·부상 | 90일 |
| 부모의 출산 | 90일 |
| 부모의 입원 | 60일 |
| 원장 허가 현장체험학습·가정학습 등 | 연 누적 30일 |
| 입양 | 20일 |
| 부모·조부모·외조부모 사망 | 5일 |
| 증조부모·형제자매 등 사망 | 3일 |
| 형제자매·부모의 결혼 | 1일 |
| 미세먼지 고농도 | 해당일 1일 |
| 감염병 보건소 모니터링 | 모니터링 기간 전체 |
| 발열·호흡기 증상 | 증상 기간 |
| 자연재해·재난 | 지자체장 인정 기간 |

### 그 밖에 확정된 것

- **신청 창구는 재원 중인 어린이집이다.** 129나 시군구가 아니다
- 절차는 결석 시작일 포함 3일 이내 통보 → 등원 가능일에 증빙서류 제출 → 어린이집이 보육통합정보시스템 처리, 서류 원내 5년 보관
- **장기 결석은 강제 퇴소 사유가 아니다.** 퇴소 예외는 영유아 질병, 어린이집 폐지, 허위서류 부정입소, 교직원 폭행, 가정폭력 피해자 요청으로 한정되고 지자체장 승인이 필요하다
- 구간·상한일수는 **전국 공통**이다. 지자체 재량은 자연재해·재난 항목뿐이다
- 질병·부상 증빙서류 완화는 2023.7.1부터 적용됐다
- **소관 부처는 교육부다.** 유보통합으로 보건복지부에서 이관됐다. 문서 표지가 `MINISTRY OF EDUCATION`으로 찍혀 있다

### 아직 확인하지 못한 것

- 경조사의 "휴무 토·공휴일 미산입"과 다른 항목의 "산입" 기본 규칙이 실제 달력 계산에서 어떻게 맞물리는지
- 2025년판 대비 변경 이력 (감염병 모니터링·발열호흡기 항목의 신설 시점 등)
- 다문화가정 해외 친척방문이 별도 인정 사유인지 (2026년판에 별도 항목명 없음 — **단정 금지**)
- 지자체 자체 보육료 사업의 출석일수 연동 여부

## D3 리서치로 확정된 사실 (2026-08-18)

### 반드시 주의할 것 (리서치·팩트체크에서 실제로 틀렸던 것들)

- **코로나19 "확진 후 5일"은 2024.5.1자로 폐지됐다.** 지금은 "주요 증상 호전 후 24시간 경과 시까지 권고"이며 격리 의무가 아니다 (질병관리청 보도자료 「코로나19 위기단계 '경계'에서 '관심'으로 하향」, 2024.4.19 배포). 아직 5일로 안내하는 블로그가 많다
- **"해열 후 24시간"은 관행이 아니다.** 질병관리청 「시설별 인플루엔자 관리지침(어린이집, 유치원, 학교용)」(2025.10.21)에 명시된 원칙이다. 해열제를 투약했다면 마지막 투약 시점부터 48시간 경과 관찰이 필요하다
- **"학교는 해열 후 24시간, 어린이집은 5일+24시간으로 더 엄격"이라는 통설은 근거가 없다.** 정부 매뉴얼 원문 어디에도 그런 차등이 없다
- 실제로 확인되는 학교와 어린이집의 차이는 **유행성각결막염**이며, 그것도 문서 차이가 아니라 **미취학 아동 대 초중고 학생**의 연령대 차이다
- **수족구병 관리지침은 2025년도판이다.** 2026년도판이 아니다
- 수족구는 완치 후에도 **최소 8주까지** 병원체가 배출될 수 있다. "등원 가능"과 "전염력 없음"은 다르다

### 아직 확인하지 못한 것

- 어린이집(영유아보육법 체계) 전용 감염병 통합 매뉴얼 원문 (질병관리청 게시물 404)
