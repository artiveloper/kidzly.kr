## 왜 이 주제들인가

[발행-완료.md](./발행-완료.md)에서 확인했듯 기존 19편은 **지원금과 제도**에 쏠려 있다. 어린이집 실무 글 5편도 전부 입소 이전 단계이고, 입소 이후를 다룬 글은 `어린이집-하루일과-연령별` 하나뿐이다.

부모가 어린이집을 다니는 내내 검색하는 **생활 영역**(준비물, 낮잠, 결석 대처)이 통째로 비어 있다. 이 문서는 그 빈자리를 3개 클러스터로 나눈 것이다.

조사 방법은 구글·네이버 노출 정보성 페이지 취합이다. 네이버 블로그탭·지식iN 원문은 직접 수집되지 않아, 검색엔진에 실제 노출되는 공공 포털·개인 블로그·육아 미디어 기준으로 정리했다.

## 클러스터 A — 입학 전 준비물과 체크리스트

카테고리는 `입소·등원 가이드`로 배치한다. 기존 `어린이집-입소-절차`가 허브이므로 그 6단계 중 "등원 준비" 단계에서 이 글들로 링크를 뻗는다.

| # | 제목 | 우선순위 | 각도 |
|---|------|---------|------|
| A1 | 어린이집 준비물 총정리, 0세부터 5세까지 연령별 목록 | ★ | 연령별 분해가 정보 이득. 경쟁 글은 대부분 단일 목록이다 |
| A2 | 어린이집 입소 서류 8가지, 등원 첫날 당황하지 않으려면 | | 동의서류(응급처치·귀가·CCTV·알레르기·차량)까지 포함 |
| A3 | 입소 전 원에 물어볼 12가지, 오리엔테이션 질문 체크리스트 | ★ | 저장·재방문형. 인쇄 가능한 형태 고려 |
| A4 | 어린이집 이름표 어디에 붙이나, 안 잃어버리는 표기 요령 | | 롱테일, 경쟁 얕음 |
| A5 | 어린이집 낮잠 이불 고르는 법과 세탁 주기 현실 기준 | | 구매 의도 키워드. B1과 내부 링크 |
| A6 | 어린이집 적응기간 2주 로드맵, 첫날부터 종일반 정착까지 | ★ | 2~3월 계절 트래픽. 단계별 일정 표 |
| A7 | 등원 첫날 분리불안, 우는 아이와 헤어지는 올바른 방법 | | "몰래 사라지지 않는다"가 핵심 메시지 |

**공통 주의.** 준비물과 서류는 원마다 편차가 크다. 글에서 "원의 최신 안내가 우선"임을 명시해야 한다.

## 클러스터 B — 입학 후 아이는 어떻게 생활하나

카테고리는 `어린이집 생활`이다. `어린이집-하루일과-연령별`이 총론을 이미 다루므로 그 글을 허브로 삼고, 여기서는 부모가 볼 수 없는 **세부 장면**으로 파고든다.

| # | 제목 | 우선순위 | 각도 |
|---|------|---------|------|
| B1 | 어린이집 낮잠 시간 몇 시부터 몇 시까지, 연령별 실제 운영 | ★ | 통상 13~15시, 만 2세는 13:30~14:30 사례. 원별 편차 명시 |
| B2 | 낮잠 안 자는 아이 억지로 재우나요, 원의 실제 대응 방식 | | "억지로 재우지 않는다"가 현장 원칙 |
| B3 | 낮잠 끊는 시기 만 3~5세, 어린이집과 집의 수면 리듬 맞추기 | | B1·B2와 3편 세트로 내부 링크 |
| B4 | 어린이집 급식 식단 확인하는 법, 편식하는 아이는 어떻게 먹나 | | 식단표·원산지 공개 의무를 근거로 |
| B5 | 어린이집 배변훈련 시기와 방법, 원과 집이 맞춰야 하는 것 | | 검색량 큼 |
| B6 | 어린이집에서 물리고 물렸을 때, 원의 대응과 부모의 대처 | | 감정 부하 높음. 톤 관리 필요 |
| B7 | 어린이집 CCTV 열람 신청 방법, 언제 어디까지 볼 수 있나 | | 영유아보육법 근거 명확. 정보 이득 큼 |

## 클러스터 D — 못 보낼 때, 아플 때, 여행 갈 때

카테고리는 D1·D2·D5가 `어린이집·보육 지원`(보육료가 걸린 문제), 나머지는 `어린이집 생활`이다.

**가장 비어 있고 가장 절박한 영역이다.** 보육료 손실이 걸린 문제인데 정확한 해설 글이 드물다.

| # | 제목 | 우선순위 | 각도 |
|---|------|---------|------|
| D1 | 어린이집 결석해도 보육료 나오나, 출석 11일 기준 완전정리 | ★1순위 | 돈이 걸린 문제. 월 11일 미만 시 차등 자부담 |
| D2 | 질병 결석은 출석 인정된다, 최대 2개월 특례와 필요 서류 | ★1순위 | 아는 부모가 드묾. 아동 질병·부상, 부모 입원이 대상 |
| D3 | 아이가 아플 때 등원중지 기준, 질병별 복귀 시점 총정리 | ★1순위 | 질병별 표 하나로 완결. 재방문형 |
| D4 | 수족구 걸린 아이 언제 다시 보내나, 완전 회복 후 등원 원칙 | | D3에서 분화. 여름 계절성 |
| D5 | 가족 여행으로 결석할 때, 보육료 지키고 자리 지키는 법 | | 여행은 출석 특례 대상이 아님이 핵심 |
| D6 | 어린이집 못 보내는 날 대체 돌봄, 아이돌봄과 시간제보육 비교 | | 서비스 연결에 유리 |
| D7 | 갑자기 아이가 아플 때 긴급 돌봄, 2~4시간 전 신청하는 법 | | 긴급돌봄 신청 가능 시간 창 안내 |
| D8 | 어린이집도 방학이 있다, 휴원일 돌봄 공백 메우는 법 | | 여름·겨울 계절성 |

## 발행 우선순위

정보 이득 × 검색 절박도 × 서비스 연결을 기준으로 추린 1차 5편이다.

| 순서 | 글 | 선정 이유 |
|------|-----|----------|
| 1 | **D1** 출석 11일 기준 | 돈이 걸렸는데 정확한 글이 없다 |
| 2 | **D3** 질병별 등원중지 기준 | 표 하나로 완결되는 재방문형 콘텐츠 |
| 3 | **A1** 연령별 준비물 | 검색 진입량이 가장 두껍다 |
| 4 | **B1** 낮잠 시간 실제 운영 | "우리 아이 지금 뭐 하나" 니즈의 정면 |
| 5 | **A3** 오리엔테이션 질문 체크리스트 | 저장·재방문형. 입소 직후 수요 |

2차는 A6(2~3월 계절 대응), D4·D8(여름 계절 대응), B7(CCTV 열람, 정보 이득 큼) 순으로 본다.
