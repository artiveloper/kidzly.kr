## 이미지별 디자인 메모

### thumbnail.png
- 밝은 블루 그라디언트 배경, kidzly 브랜드 상단 좌측
- 핵심 정보(만 0세 100만원, 만 1세 50만원, 60일 이내 신청)를 칩 형태로 하단에 노출

### section_01_금액.png
- 흰 배경, 만 0세(파랑)/만 1세(초록) 카드 구분
- 하단 노트에 아동수당 중복 수령 정보(월 최대 110만원) 포함

### section_02_어린이집차액.png
- 다크 배경으로 차별화, 테이블 구조로 바우처·차액 한눈에 비교
- 만 0세 416,000원 차액(녹색 강조), 만 1세 차액 없음(어두운 강조)
- 하단 노트에 근거(복지로·보건복지부) 출처 표기

### section_03_신청방법.png
- 흰 배경, 3단계 스텝 UI, 각 단계별 색상 구분
- 하단 경고 박스(빨강)로 60일 기한 강조

## 사용 가이드
- 파일 위치: `_workspace/images/*.png`
- 블로그 삽입 위치:
  - thumbnail.png → 글 상단 대표 이미지
  - section_01_금액.png → "지급 금액은 얼마인가요?" 섹션 하단
  - section_02_어린이집차액.png → "어린이집을 이용하면 어떻게 받나요?" 섹션 하단
  - section_03_신청방법.png → "어떻게 신청하나요?" 섹션 하단
- 권장 파일 형식: PNG → WebP 변환 권장 (용량 최적화)
- Alt 텍스트:
  - thumbnail.png → `부모급여 총정리 금액 신청방법 어린이집 차액 인포그래픽`
  - section_01_금액.png → `부모급여 만0세 100만원 만1세 50만원 매월 25일 지급`
  - section_02_어린이집차액.png → `어린이집 이용 시 부모급여 바우처 차액 계산 만0세 416000원`
  - section_03_신청방법.png → `부모급여 신청방법 출생 60일 이내 복지로 정부24 행정복지센터`
