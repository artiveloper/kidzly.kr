# 리서치 브리프 — 부모급여 총정리

## 핵심 키워드
- 메인 키워드: 부모급여 (검색량 높음, 부모 필수 관심사)
- 서브 키워드: 부모급여 신청방법, 부모급여 금액, 영아수당, 부모급여 어린이집
- 롱테일 키워드: 부모급여 어린이집 차액, 부모급여 신청기간 60일, 부모급여 아동수당 중복, 부모급여 지급일, 부모급여 온라인 신청, 부모급여 복지로, 부모급여 언제부터

## 독자 인사이트
(맘카페·커뮤니티 기반, 실제 부모 질문)
- "어린이집 보내면 부모급여 못 받나요?" → 차액 지급 방식 혼란 가장 많음
- "신청을 늦게 하면 소급 적용이 안 되나요?" → 60일 규정 몰라서 놓치는 경우 多
- "아동수당이랑 같이 받을 수 있어요?" → 중복 수령 여부 혼동
- "부모급여가 영아수당이랑 같은 건가요?" → 명칭 변경 이력 혼동
- 직장 복귀 후에도 계속 받을 수 있는지 문의 다수

## 콘텐츠 방향
- 차별화 포인트: "어린이집 이용 시 차액 지급" 구조를 표로 쉽게 시각화 — 부모 혼란 해소
- 권장 글 구조:
  1. 부모급여란 무엇인가 (개요)
  2. 지급 대상과 금액
  3. 어린이집 이용 시 지급 방식 (바우처 + 차액)
  4. 신청 방법·기간 (60일 규칙 강조)
  5. 자주 묻는 질문 (아동수당 중복, 직장 복귀 후 수령 여부)
- 포함할 핵심 논점: 60일 신청 기한, 차액 지급 계산 구조, 아동수당 중복 가능

## 리서치 한계

- 항목: 부모급여 지급일 (매월 몇 일인지) / 이유: 명확한 공식 자료 미확인. 팩트체커 확인 필요.
- 항목: 아동수당 중복 수령 여부 / 이유: 중복 가능하다는 정보가 다수이나 원문 법령 확인 필요.
